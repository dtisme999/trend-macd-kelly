# 精确 MACD 筛选、市场情景与仓位状态机设计

## 目标

把现有“近似版”策略改为严格对应用户需求、可复现且可测试的日线回测：

1. MACD 负柱连续 2–7 根，当前为首次收敛，紧邻的前一正柱段不少于 7 根，正柱最大值与当前负柱段最小值绝对值之比不低于 2。
2. 市场和个股都划分为上升、下跌、震荡，并输出分情景表现。
3. 首仓 5%、加仓至 10%，以首笔实际成交价 `A` 为唯一价格锚点，执行 0.94/1.01/1.03/1.10/1.20/1.30/1.40 阈值和 5 个交易日超时。

## 固定口径

- `MACD` 指项目既有的柱值 `hist = 2 * (DIF - DEA)`。
- `1.10/1.20/1.30/1.40` 表示相对 `A` 上涨 10%/20%/30%/40%。
- 所有阈值由当日收盘价判断，订单在下一可交易日开盘价加滑点成交，避免使用当日尚未知的未来价格。
- “收敛数量为 1”定义为：当前 `abs(hist)` 小于前一日 `abs(hist)`，且前一日不是收敛；即当前是连续收敛序列的第 1 根。
- “最新连续负值的最小值”只使用负柱段截至当前的历史值，取绝对值最大的负柱；不得窥视该负柱段未来数据。
- MACD 五项条件构成完整入场筛选；旧 `trend_score_min` 不再额外阻断信号。趋势分类只用于分组对比。

## 信号数据流

单只股票按日期排序后分割正负柱段，逐日输出：

- `prior_pos_run`：紧邻前一正柱段长度；
- `neg_run_k`：当前负柱段截至当日的长度；
- `convergence_count`：连续收敛计数；
- `prior_pos_max`：紧邻前一正柱段最大柱值；
- `current_neg_min`：当前负柱段截至当日最小柱值；
- `macd_strength_ratio = prior_pos_max / abs(current_neg_min)`；
- `entry_candidate`：五项规则的合取。

这些字段全部只依赖当日及历史数据。

## 市场情景与个股趋势

市场基准和每只股票使用相同、可解释的三分类：

- 上升：`close > MA60`、`MA20 > MA60`、`MA60` 的 20 日变化为正；
- 下跌：三个条件完全反向；
- 其余（含指标预热期）：震荡。

特征表新增 `market_regime` 和 `stock_trend`。每笔交易记录入场时的两个标签。报告输出：

- 按市场情景聚合的日收益样本数、累计收益、年化收益、波动、夏普和胜率；
- 按个股入场趋势聚合的交易数、平均收益、胜率、盈亏合计。

## 仓位状态机

- S1：首仓目标 5%。`close <= 0.94A` 止损；5 个交易日仍未触及 `1.10A` 超时退出；触及 `1.10A` 后挂 5% 加仓单。
- S2：总目标 10%。`close <= 1.03A` 止损；加仓后 5 个交易日仍未触及 `1.20A` 超时退出；未触及 `1.20A` 而回落至 `1.01A` 退出；触及 `1.20A` 减持初始总数量的 1/3。
- S3：剩余约 2/3。未触及 `1.30A` 而回落至 `1.08A` 全退；触及 `1.30A` 再减持初始总数量的 1/3。
- S4：剩余约 1/3。未触及 `1.40A` 而回落至 `1.15A` 全退；触及 `1.40A` 全退。

部分减仓以“完成加仓后的峰值总股数”为基准保存目标数量，避免连续按剩余仓位乘比例产生累计误差。模拟阶段按整数股计算，不引入整手和零股申报限制；最后一次退出清空全部余量。

## 测试与验收

- 纯信号单元测试覆盖每一个 MACD 边界以及无未来信息。
- 纯状态机测试覆盖所有阈值、优先级、5 个交易日边界。
- 执行器集成测试验证 T+1、5%/10% 仓位、两次固定基数减仓和交易标签。
- 情景分类及分组表现测试验证只有三类且聚合结果可重算。
- 使用项目真实缓存行情运行端到端回测，检查信号数量、成交状态序列、报告非空及无异常。
